## 5. 안정적인 극한 귀환을 위해 적용한 핵심 개선 사항

1. **SpaceX 7단계 RTLS 아키텍처 단일화 및 물리 경계 분리 (`Plant ↔ Forces ↔ GNC`)**
   - `ascent → flip → boostback → coast → entry_burn → aero_glide → landing_burn → touchdown_settle`
     전 과정을 단일 통합 엔진(`rtls/`)으로 일원화하고, 구버전 이중 모드 및 레거시 코드를 전부 제거했습니다.
   - 역방향 하강 둔체 항력($C_{D,\text{descent}} = 1.65$), 격자핀 유효 받음각·힌지 모멘트 한계,
     3기 엔진 클러스터(엔진당 최소 스로틀 44%, 최대 재점화 3회) 및 호버링 불가 3→1 호버슬램,
     접지 후 5초 착륙다리 스프링-댐퍼·마찰·직립 동역학을 통합 모델링했습니다.
2. **인과적 온라인 항력·밀도 스케일 추정 (`_predict_rtls_iip`)**
   - 무동력 활강(`aero_glide`) 중 인과적 가속도 바이어스 추정치(`est.accel_bias_z_m_s2`)로부터
     실제 대기 밀도·항력 배율(`drag_scale_est ∈ [0.75, 1.35]`)을 실시간 추정하여 IIP(예상 낙하점)
     예측에 반영함으로써, +26.5% 복합 고항력·강풍 조건의 활강 끝단 편차를 대폭 줄였습니다.
3. **해석적 제로-틸트 복귀 예측기 (`_predict_zero_tilt_state`)**
   - 유한 자세 각가속도(`2.15 deg/s²`)로 현재 기울기·각속도 `(θ, ω)`를 `(0, 0)`으로 되돌리는 동안
     필연적으로 발생하는 수평 변위와 속도 변화 `(x_lead, vx_lead)`를 해석적으로 적분하여,
     종말 Stage B의 리미트-사이클 진동과 과잉 선회를 원천 차단했습니다.
4. **Stage A 전환 선행 예측 및 Stage B 무오버슈트 속도 상한 (`v_no_overshoot`)**
   - 3엔진 Stage A 구간에서 Stage A→B 전환 시점의 수평 드리프트를 선행 예측(`x_stage_a`)해
     강풍·활강 잔여 횡속도를 높은 추력 구간에서 조기 제거합니다.
   - 1엔진 Stage B 구간에 잔여 접지 시간 기반 무오버슈트 상한(`v_no_overshoot = k · |x_lead| / t_eff`)을
     도입하여, 저고도 수직 정렬 직전의 늦은 재가속과 패드 통과 오버슈트를 방지했습니다.
5. **잡음 내성 수직 정렬 래치 및 구간 일치형 TVC/RCS 제어 할당**
   - `vertical_body` 전환 고도를 단방향 결정론적 래치(`h ≤ 21.5 m`)로 고정해 ±2 m 항법 잡음에 의한
     모드 채터링과 조기 트리거를 제거했습니다.
   - `PriorityControlAllocator`에서 수직 정렬 구간의 짐벌 스텝을 제한(`≤ 0.85°/tick`)하고,
     제어 구간 `[t, t+Δt]` 내 실제 TVC·핀 토크 변화에 맞춘 구간 일치 RCS 상쇄 토크를 계산해
     1-스텝 명령 지연과 접지 직전 급돌풍에서도 전 487케이스 최대 각가속도를 `≤ 4.36 deg/s²`로 억제했습니다.
6. **연속 접지 테이퍼 및 비대칭 호버슬램 수직 제동**
   - 접지 직전 불연속 임계치 전환을 연속 smoothstep 테이퍼(`always_td_taper`)로 대체하고,
     과속 하강 시 비대칭 제동 이득(`k_v = 2.7`)과 저고도 MECO-3 컷오프 가드를 결합해
     엔진 최소 추력(`TWR_min > 1`)에서도 반등 없이 `0.159–1.430 m/s`의 부드러운 접지와
     5초 직립 안정을 전 487케이스에서 달성했습니다.

## 6. 재현 명령

```bash
# 극한 엣지 32케이스 빠른 검증 (~1.5분)
python scripts/evaluate_validation.py --suite edge-cases --workers 8

# 전체 487케이스 일괄 검증 및 JSON 저장
python scripts/evaluate_validation.py --suite full-487 --workers 14 --out-json artifacts/validation-487.json

# 단일 대표 비행 및 50 Hz 3D 리플레이 JSON 내보내기
python scripts/run_flight.py --scenario example-weather --export-replay artifacts/example_weather_replay_50hz.json
```
