# 3톤 APR 모델 기술 명세

[English](spec.md) · [README](../README.ko.md)

현재 Aero-PID Return(APR) 시뮬레이터의 좌표, 입력, 사건, 성공 판정을
정의합니다. 잠정적인 2차원 모델이며 실제 기체의 보정된 모델이나 발사
안전 인증이 아닙니다.

## 기체와 계산 범위

발사 질량은 3,000 kg입니다. 1단 건조질량 520 kg, 주 추진제 1,450 kg,
RCS 추진제 15 kg, 2단·탑재체 1,015 kg이며 탑재체 30 kg은 이미 1,015 kg에
포함됩니다. 건조질량 배분은 엔진 110 kg, 동체·기타 계통 326 kg,
다리 60 kg, 제어핀 24 kg입니다. 치수와 부품 특성은 등가 설계 가정이며
실제 부품 목록이 아닙니다.

주엔진은 해수면 추력 42 kN, 공칭 비추력 260 s, 출구 면적 0.02 m²입니다.
스로틀은 연속 0-100%, 짐벌은 ±6°입니다. RCS는 최대 6,000 N·m,
비추력 220 s를 가정하며 주 추진제와 별도로 소비합니다.

전체 비행과 분리 이후 비행은 동일한 `AprFlight` 구현을 사용합니다.
전체 비행은 상승, 10 km 분리, 1단 귀환, 다리 접촉, 엔진 정지,
안정 지지를 포함합니다. **2단의 700 km 궤도 투입은 가정이며
계산하거나 검증하지 않습니다.** 3차원 비행 모델도 없습니다.

## 좌표와 상태

발사 패드가 원점이며 +x는 화면 오른쪽·동쪽, +z는 위쪽입니다.
위치는 로켓 하단이나 발이 아니라 **순간 질량중심**을 뜻합니다.
기체 내부 위치는 동체 하단부터 위쪽으로 측정합니다.
자세각은 수직에서 시계방향으로 양수이며, 양의 짐벌은 추력 방향을
더 시계방향으로 돌립니다.

~~~text
추력_x = 추력 * sin(자세각 + 짐벌각)
추력_z = 추력 * cos(자세각 + 짐벌각)
시계방향_토크 = 팔_z * 힘_x - 팔_x * 힘_z
~~~

x·z 병진과 한 축의 회전을 가진 평면 강체 모델입니다.

| 상태 인덱스 | 물리량 | 단위 |
|---|---|---|
| 0, 1 | 질량중심 x, z | m |
| 2, 3 | 수평·수직 속도 | m/s |
| 4, 5 | 자세각·각속도 | rad, rad/s |
| 6, 7 | 주 추진제·RCS 추진제 | kg |
| 8 | 다리 전개율 | 0-1 |
| 9, 10 | 좌·우 발의 접선 방향 접촉 변형 | m |
| 11 | 실제 핀 편향각 | rad |
| 12 | 핀 전개율 | 0-1 |

제어 입력은 `[스로틀, 짐벌_rad, RCS_토크_Nm, 핀_목표각_rad]`입니다.
형상, 발의 속도, 애니메이션은 질량중심 이동과 기체 회전을 반영합니다.
520 kg 건조질량은 별도 상태나 잔여 연료 목표가 아닙니다.

## 물리와 제어

| 항목 | 현재 연결된 구현 |
|---|---|
| 병진·회전 | 가변 질량, 평행축 관성모멘트, 질량중심 및 관성 변화율 |
| 환경 | 고도별 중력, 대류권·등온층 대기 근사, 국소 코리올리 효과 |
| 엔진 | 해수면 기준 압력 보정, 질량 유량, 선택적인 1차 응답 지연 |
| 동체 공력 | 공기 상대 속도의 축·횡 항력, 압력중심 모멘트, 회전 감쇠, 천음속 보정 |
| 핀 | 제한된 등가 양력·항력, 토크·힌지 하중, 전개 및 서보 동역학 |
| 유도·제어 | 예보 기반 귀환 제동·점화, 수평 정렬·하강 동기화, PID 계열 피드백과 구동기 배분 |
| 다리·접촉 | 전개, 단방향 스프링·댐퍼 수직력, 탄성 고착·쿨롱 미끄러짐, 압축·힘 한계, 동체 지면 충돌 |
| 착륙 후 | 엔진 정지 관찰과 연속적인 안정 유지 시간 |

제어 주기는 고정 0.01 s입니다. RK4 적분은 비행 중 0.01 s,
지면 근처 0.001 s이며 적분 간격 변경이 제어 주기를 바꾸지는 않습니다.
`advance()` 호출 사이에 센서·명령 큐, 엔진 응답, 제어기 기억, 추진제를
유지합니다. RK4 내부 단계마다 위치·시간에 맞는 바람과 대기를 계산합니다.

핀 계수는 가정이며 Falcon 9의 실측 그리드핀 계수가 아닙니다.
전개한 핀의 성공 판정 범위는 마하수 ≤0.8, 받음각 절댓값 ≤25°,
핀당 힌지 하중 ≤400 N·m입니다. 범위 밖의 성능을 검증한 모델이 아닙니다.

## 운용 입력

`configs/apr-operating-v1.yaml`은 스키마 1, 기준 시드 **378**,
모든 필드와 고정 기체 제원을 요구합니다.
알 수 없는·누락된 필드와 허용하지 않는 조건은 출력 폴더 생성 전에 거부합니다.

| 입력 | 프로젝트의 잠정 범위 |
|---|---|
| 고도별 바람 | 실제·예보 각각 0-20 km를 덮는 증가 순서의 선형 보간 프로파일 |
| 지상풍 | 0-50 m 구간에서 지속풍·돌풍 진폭을 합한 최악값 ≤13.4 m/s |
| 상층풍·윈드시어 | 돌풍 포함 최악 풍속 ≤28 m/s, 프로파일 변화율 ≤4 m/s/km |
| 돌풍 | 사인파 진폭 0-2 m/s, 주기 8-60 s, 위상 ±pi 이내 |
| 예보 오차 | 돌풍 포함 실제·예보 차이 최악값 ≤2 m/s |
| 해수면 온도·압력 | 273.15-308.15 K / 95-105 kPa |
| 정상 추력·관성 배율 | 0.98-1.02 / 0.97-1.03 |
| 센서 잡음 배율 | 0-1 |
| 관측·명령 지연 | 제어 주기 0-2회 / 0-1회 |
| 엔진 지연 | 0-0.05 s |
| 수동 검토 | 건전성·번개/구름·온도·회수 지역 검토 통과 |
| 제외 조건 | 알려진 고장, 강수, 뇌우, 우박 |

13.4 m/s 지상풍 참고값은 Falcon 9 Crew Dragon의
[162 ft 높이 지속풍 30 mph 기준](https://www.nasa.gov/wp-content/uploads/2021/07/falcon9_crewdragon_launch_weather_criteria_fact_sheet.pdf)에서
출발했습니다. 이를 0-50 m의 **지속풍과 돌풍 합계**에 적용한 것은 별도의
보수적 프로젝트 규칙입니다. 다른 상한도 합성 실험 가정이지 이 기체의
공인된 발사 한계가 아닙니다. 검토 여부는 번개·구름 물리, 실시간 날씨,
실제 발사 승인을 대신하지 않습니다. 입력 허용과 비행 가능성은 다릅니다.

실제 바람과 추력·관성 편차는 물리계에 적용합니다. 제어기는 예보 바람과
공칭 제원, 잡음·지연이 있는 관측의 인과적 추정만 사용합니다.
잡음 배율 1의 표준편차는 위치 0.5 m, 속도 0.1 m/s, 자세 0.25°,
각속도 0.25°/s입니다. 연료·구동기·최대 동압 계측은 이상적인 정보를
가정합니다. 성공은 실제 상태로 판정하며 허용 입력의 실패를 평가에서
빼지 않습니다. 20 km 대기 프로파일을 벗어나면 영역 판정에 실패합니다.

## 사건과 성공 기준

분리는 관측된 최대 동압 통과 후 고도 10,000 ±100 m,
기울기 9±0.5°, 동압 ≤25 kPa, 받음각 ≤5°, 각속도 ≤5°/s를 목표로 합니다.
분리 준비는 받음각 2°, 각속도 2°/s의 더 엄격한 조건과 0.3 s 유지 시간을
사용합니다. 전체 비행에서는 잡음 관측뿐 아니라 실제 상태도 통과해야 합니다.
분리 시 1단 질량중심 좌표로 바꾸되 기체의 물리적 위치·국소 속도를 일관되게
유지하며 속도를 0으로 초기화하지 않습니다.

| 구간 | 요구 조건 |
|---|---|
| 상승 | 동압 ≤30 kPa, Q-alpha ≤150 kPa·deg, 동압 ≥10 kPa에서 받음각 ≤5° |
| 상승 운동 | 각속도 ≤15°/s, 각가속도 ≤5°/s², 축방향 가속도 ≤3 g |
| 회수 운동 | 정상 하중 ≤5 g·절대 한계 6 g, 각속도 ≤15°/s, 각가속도 ≤5°/s² |
| 착륙 접근 | 기울기 ≤5°, 200 m 위에서 정렬 조건과 유지 시간 완료 |
| 접지 | 질량중심 위치 오차 ≤2 m, 발 수직속력 ≤1 m/s, 발 수평속력 ≤0.5 m/s |
| 접지 자세 | 기울기 ≤3°, 각속도 ≤0.5°/s |
| 추진제 | 주 추진제 >0 kg, RCS ≥0 kg, 추가 최소 잔량 없음 |
| 다리·패드 | 다리 잠금, 발이 ±10 m 패드 안, 압축 ≤0.3 m, 발당 수직력 ≤18 kN |
| 접지 이후 | 엔진 정지, 관찰 ≥3 s, 연속 안정 유지 ≥1 s |

최종 하강 목표는 0.9 m/s입니다. 접촉·하중, 동체 충돌, 질량 수지,
해당 핀 한계도 통과해야 합니다. 상태를 덮어써서 성공을 만들지 않습니다.

`from_separation()`은 1단 질량중심 기준 13개 상태, 사건 시각,
이전 최대 동압 통과 확인, 좌표 변경 전 분리 고도, 실제 스로틀을 받습니다.
운동과 연료를 유지하지만 제어기 기억은 새로 시작합니다.
회수 전용 결과에서 상승 기준은 `null`로 두고
`not_evaluated_criteria`에 기록하며 이전 최대 동압 확인을 독립적으로
재검증한 것으로 처리하지 않습니다.

## 결과와 한계

`result.json`에는 `design`, `physics`, `state_names`, `steps`,
`separation`, `first_contact`, `criteria`, `outcome`,
`simulated_acceptance_passed`, `simulation_scope`,
`not_evaluated_criteria`, 입력 조건·시드·연료를 기록합니다.
실행기는 소스·입력 해시를 추가하며 기존 결과를 덮어쓰지 않습니다.
저장한 해시는 해당 결과 생성 당시 코드의 해시이며 이후 코드 정리가
과거 결과의 해시를 갱신하지는 않습니다.

보관한 비행 근거는 무풍 전체 비행 개발 사례 한 건과 구현 검사입니다.
날씨별 성공률 추정이나 독립적인 인증 시험을 마친 결과가 아닙니다.
애니메이션은 저장된 상태를 정상 배속으로 재생할 뿐 새 비행 실험이나
성공 근거를 추가하지 않습니다.

**미연결:** 액체 수집·보유, 탱크 가압·공급, 연료 출렁임 연성,
점화·재점화, 탄성 구조, 실제 분리 충격, 2단 점화·플룸,
세부 열·지면 손상, 다리 재료·패드 강도.
힘·압축·접촉 한계 검사는 연결했지만 재료 강도나 실물 안전을 확정하지
않습니다. 남아 있는 치수·재료 필드는 가정이며 사용하지 않는 계통
파라미터가 존재한다고 해당 해석이 연결된 것은 아닙니다.
