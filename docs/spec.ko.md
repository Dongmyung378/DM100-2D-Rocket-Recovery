# DM100 2D Orbital Reusable RTLS 모델 명세

[English](spec.md) | [README](../README.ko.md) | [검증 설계](validation.ko.md) | [검증 결과](results.ko.md)

실물 비행 인증을 받은 기체가 아닌 이론적 **2차원 소프트웨어 개념 모델**입니다.
기준 시드는 **378**입니다. 총질량 100톤 2단 메탈록스(LCH₄/LOX) 로켓이 7기 엔진으로 발사해 고고도(`53~71 km`)에서 콜드 분리한 뒤, **2단은 구면 지구 2회 연소 적분으로 700 km 원궤도(1,800 kg 탑재체)에 진입**하고 **1단은 원래 발사장으로 RTLS 귀환·착륙·5초 직립**까지 수행합니다.

## 1. 기체 질량 및 기하 배분

| 항목 | 모델 값 |
|---|---:|
| 1단 엔진 (7기 메탈록스 클러스터) | 1,050 kg |
| 1단 구조, 탱크, 공급·가압·배플·분리 시스템 | 3,750 kg |
| 착륙장치 (좌/우 평면 스트럿) | 800 kg |
| 격자핀 4개 및 구동기·전개 장치 | 600 kg |
| **1단 건조질량 합계** | **6,200 kg** |
| 1단 주 추진제 (LCH₄/LOX) / RCS 추진제 | 69,500 / 300 kg |
| **1단 초기 질량** | **76,000 kg** |
| 2단 건조질량 / 추진제 / 탑재체 | 1,550 / 20,650 / 1,800 kg |
| **총 발사 질량** | **100,000 kg** |

- 1단 몸체: 길이 `24.0 m`, 직경 `3.1 m` (`반지름 1.55 m`, 상단 길이 `9.0 m`, 집중 질량중심 1단 하단 기준 `28.0 m`).
- 격자핀: 설치 위치 `22.4 m`, 4개 전체 면적 `6.0 m²` (평면 등가 유효 면적 `3.0 m²`), 초음속 프란틀-마이어 유효 양력 경사 보정, 최대 조향각 `±20°`, 힌지 모멘트 한계 `7,500 N·m`, 기본 항력계수 `0.35`.
- 착륙장치: 반폭 `4.0 m`의 좌/우 스트럿, 패드 반폭 `10.0 m`, 스트럿 스프링-댐퍼 + 쿨롱 지면 마찰 접촉 모델 적용 (`최대 압축 ≤ 0.90 m`, `접촉 하중 ≤ 4.0 g`).
- 추진제 공급·가압·슬로시·분리: 유지형 액체 버퍼 `1,500 kg`(주 추진제 내부 포함), 헬륨 `75 kg` 폐쇄 가압, 비선형 진자 액체 출렁임(slosh), 운동량 보존 콜드 분리 충격량 모델 포함.

## 2. 추진 · 공력 · 열환경 · 8단계 궤도 RTLS 비행 시퀀스

| 항목 | 모델 값 |
|---|---|
| 1단 7기 클러스터 해면 / 진공 추력 | 1,550 kN (7 × 221.4 kN) / 1,693 kN |
| 1단 해면 / 진공 비추력 (LCH₄/LOX) | 325 s / 355 s |
| 1단 엔진당 최소 스로틀 / 최대 재점화 | **36%~100%** / **최대 3회** (중앙 1기 최소 추력 `79.7 kN`, 빈 1단 대비 `TWR_min > 1.0`) |
| TVC 짐벌 범위 / 구동 속도 / 시정수 | ±6° / 60°/s / 0.06 s |
| RCS 비추력 / 최대 토크 | 260 s / 100,000 N·m |
| 2단 진공 엔진 추력 / 비추력 | 240 kN / 380 s (2회 연소 700 km 원궤도화, 지구 자전 속도 반영) |
| 상승 / 역방향 하강 축방향 항력계수 | $C_{D,\text{ascent}} = 0.40$ / $C_{D,\text{descent}} = 1.65$ (천음속 항력 상승 포함) |
| 재진입 정체 열유속 모델 | Sutton-Graves 모델 ($\dot{q} \le 80\ \text{kW/m}^2$, 유효 노즈 반경 적용) |

### 비행 단계 (`rtls/guidance.py`, `rtls/orbit.py`)
1. **7엔진 상승 및 콜드 분리 (`ascent`)**: 중력 턴 상승 후 1단 잔여 주추진제 게이트(`12,300 kg` 최소 여유, 고도 `53~71 km`)에서 MECO-1 및 콜드 단 분리.
2. **2단 700 km 원궤도 투입 (`rtls/orbit.py`)**: 분리 순간의 고도·속도 및 발사장 위도의 지구 자전 속도를 초기값으로 구면 지구 2회 연소(천이 궤도 상승 + 원지점 원궤도화)를 적분하여 **`700 ± 15 km` 원궤도 도달 및 잔여 추진제 > 0 kg** 여부를 판정.
3. **저동압 반전 (`flip`)**: 분리 직후 진공/저동압 구간에서 RCS로 신속히 자세 반전.
4. **3엔진 부스트백 (`boostback`, 재점화 #1)**: 유한 연소 예측 보정으로 발사장 활강 진입창으로 탄도 궤적 전환.
5. **탄도 귀환 (`coast`)**: 고도 `120~170 km` 정점 통과 후 하강 시 격자핀 전개.
6. **단축 재진입 연소 (`entry_burn`, 재점화 #2)**: 무추력 예측 동압 `> 26.5 kPa` 또는 열유속 `> 62 kW/m²` 구간에서만 `0.85 s` 점화 램프 적용 3엔진 역추진 후 MECO-2 완전 소화.
7. **무동력 격자핀 활강 (`aero_glide`)**: 주추진제 명령 `0%` (`25.0~43.0 km` 활강). 초음속 고고도(`z ≥ 27 km`) `5°` 받음각 제한과 인과적 온라인 항력·밀도 배율 추정(`_predict_rtls_iip`)으로 발사장 상공까지 정밀 유도.
8. **3→1 최소 스로틀 호버슬램 (`landing_burn`, 재점화 #3) & 5초 직립 (`touchdown_settle`)**:
   - 고고도 3엔진 감속(Stage A) → 중앙 1엔진 전환(Stage B, 호버링 불가 Hoverslam).
   - <strong>해석적 자세 복귀 예측기(<code>_predict_zero_tilt_state</code>)</strong>, 저역통과 필터링된 수평 가속도 편향(`bias_x`), 수직 정렬 진입 `0.28 s` 각가속도 램프 및 거리 인식형 수평 제동으로 전 487케이스에서 모든 제약을 **80% 이하**로 유지.
   - 볼록 최적화(LP) 종말 참조 플래너 및 우선순위 제어 할당(`격자핀 → TVC → RCS`) 적용.
   - 접지 직후 엔진 종료 및 **5초 무동력 착륙다리 스프링-댐퍼·마찰 직립 정착** 판정.

## 3. 운용 입력 범위 및 판정 기준

### 허용 입력 범위 (`AprConditions`, `RecoveryDisturbances`, `SensorSettings`)
- 바람/돌풍: 지상풍 `±8 m/s`, 상층풍 `±20 m/s`, 수직풍 `±3 m/s`, 예보 오차 `±2 m/s`, 돌풍 진폭 `0~5 m/s` (주기 `8~60 s`).
- 대기: 지상 기온 `0~35 °C`, 기압 `95~105 kPa`, 대기밀도 배율 `0.90~1.10` (최종 밀도는 기준 대기 대비 ±10% 이내), 위도 `-90° ~ +90°`(코리올리 및 지구 자전 포함).
- 기체 편차·지연·센서: 추력 배율 `0.97~1.03`, 항력 배율 `0.85~1.15`, 초기 질량 배율 `0.99~1.01`, 관성 배율 `0.97~1.03`, 위치 오차 `0~2 m`, 속도 오차 `0~1 m/s`, 관측 지연 `0~2 step`, 명령 지연 `0~1 step`, 엔진 지연 `0~0.05 s`, 확장 IMU 자세/자이로 잡음·편향(`≤ 0.1°`, `≤ 0.1°/s`, `±0.05`) 및 패킷 누락(`최대 2/20`).

### 합격 판정 기준 (모두 동시 충족)
- **임무 및 궤도**: 콜드 단 분리 충족 및 **2단 700 ± 15 km 원궤도 투입(1,800 kg 탑재체, 잔여 추진제 > 0 kg)**.
- **비행 안전**: 최대 동압 `≤ 42 kPa`, 최대 정체 열유속 `≤ 80 kW/m²`, 상승 `q·α ≤ 150 kPa·deg`, 고동압 받음각 `≤ 5.0°`, 상승 축방향 하중 `≤ 4.5 g`, 회수 하중 `≤ 5.5 g`, 최대 각속도 `≤ 15°/s`, 최대 각가속도 `≤ 5.0°/s²`, 짐벌 `≤ 6°`, 핀 힌지 모멘트 `≤ 7,500 N·m`, 질량·헬륨 보존 및 공급·슬로시 정상.
- **최초 접지**: 중심 위치 오차 `|x| ≤ 2.0 m`, 다리 끝점 수직 속도 `≤ 1.5 m/s`, 수평 속도 `≤ 0.5 m/s`, 기울기 `≤ 3.0°`, 각속도 `≤ 0.5°/s`, 주추진제 `> 0 kg`, RCS `≥ 0 kg`, 착륙다리 완전 전개 및 패드 내부 접지.
- **접지 후 5초 직립 (`contact_dynamics`)**: 스트럿 압축 `≤ 0.90 m`, 다리 하중 `≤ 250 kN`, 접촉 하중 `≤ 4.0 g`, 동체 지면 충돌 없음, 5초 무동력 정착 후 직립 유지(`final_tilt ≤ 5.0°`, `final_speed ≤ 0.08 m/s`, `final_rate ≤ 0.5°/s`).
