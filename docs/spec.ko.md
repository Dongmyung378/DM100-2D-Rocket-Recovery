# DM100 2D SpaceX RTLS 모델 명세

[English](spec.md) | [README](../README.ko.md) | [검증 설계](validation.ko.md) | [검증 결과](results.ko.md)

실물 비행 인증을 받은 기체가 아닌 이론적 **2차원 소프트웨어 개념 모델**입니다.
기준 시드는 **378**입니다. 발사 후 약 37 km에서 콜드 분리하고 1단을 원래
발사장으로 회수합니다. 상단의 500 kg 탑재체와 700 km 원궤도 진입은 성공을
가정하며 2단 비행은 적분하지 않습니다.

## 1. 기체 질량 및 기하 배분

| 항목 | 모델 값 |
|---|---:|
| 1단 엔진 (3기 클러스터) | 1,200 kg |
| 1단 구조, 탱크, 공급·가압·배플·분리 시스템 | 8,700 kg |
| 착륙장치 (좌/우 평면 스트럿) | 1,500 kg |
| 격자핀 4개 및 구동기·전개 장치 | 600 kg |
| **1단 건조질량 합계** | **12,000 kg** |
| 1단 주 추진제 / RCS 추진제 | 70,200 / 300 kg |
| **1단 초기 질량** | **82,500 kg** |
| 2단 건조질량 / 추진제 / 탑재체 | 1,500 / 15,500 / 500 kg |
| **총 발사 질량** | **100,000 kg** |

- 1단 몸체: 길이 `20 m`, 직경 `3 m` (상단 길이 `8 m`, 집중 질량중심 1단 하단 기준 `24 m`).
- 격자핀: 4개 전체 면적 `6 m²` (평면 등가 유효 면적 `3 m²`), 유효 받음각 $\alpha_{\text{eff}} = \alpha_{\text{body}} + \delta_{\text{fin}}$, 최대 조향각 `±20°`, 힌지 모멘트 한계 `5,000 N·m`, 기본 항력계수 `0.35`.
- 착륙장치: 반폭 `4 m`의 좌/우 스트럿, 패드 반폭 `10 m`, 스트럿 스프링-댐퍼 + 쿨롱 지면 마찰 접촉 모델 적용.
- 추진제 공급·가압·슬로시·분리: 유지형 액체 버퍼 `1,500 kg`(주 추진제 내부 포함), 헬륨 `65 kg` 폐쇄 가압, 단순화 액체 흔들림(slosh), 운동량 보존 콜드 분리 충격량 모델 포함.

## 2. 추진 · 공력 · 7단계 RTLS 비행 시퀀스

| 항목 | 모델 값 |
|---|---|
| 3기 클러스터 해면 / 진공 추력 | 1,600 kN (3 × 533.3 kN) / 약 1,760 kN |
| 해면 / 진공 비추력 | 300 s / 약 330 s |
| 엔진당 최소 스로틀 / 최대 재점화 | **44%–100%** / **최대 3회** (중앙 1기 최소 추력 `234.7 kN`, 빈 1단 대비 `TWR > 1.0`) |
| TVC 짐벌 범위 / 구동 속도 / 시정수 | ±6° / 15°/s / 0.05 s |
| RCS 비추력 / 최대 토크 | 220 s / 100,000 N·m |
| 상승 / 역방향 하강 축방향 항력계수 | $C_{D,\text{ascent}} = 0.40$ / $C_{D,\text{descent}} = 1.65$ (천음속 항력 상승 포함) |

### 비행 단계 (`rtls/guidance.py`)
1. **상승 및 콜드 분리 (`ascent`)**: 중력 턴 상승 후 `37 ± 1 km`, 주 추진제 `≥ 20,000 kg`, `q ≤ 25 kPa` 게이트에서 콜드 분리.
2. **저동압 반전 (`flip`)**: 분리 직후 진공/저동압(`q ≤ 250 Pa`) 구간에서 RCS로 신속히 자세 반전.
3. **부스트백 (`boostback`, 재점화 #1)**: 3엔진 유한 연소 예측-보정으로 발사장 활강 진입창으로 탄도 궤적 전환.
4. **탄도 귀환 (`coast`)**: 고도 `36 km` 이하 하강 시 격자핀 전개.
5. **단축 재진입 연소 (`entry_burn`, 재점화 #2)**: 무추력 예측 최대 동압이 `25 kPa` 여유를 넘을 구간에서만 짧게 역추진 후 MECO-2 완전 소화.
6. **무동력 격자핀 활강 (`aero_glide`)**: 주추진제 소모 `0 kg`. 인과적 항법 가속도 편향(`est.accel_bias_z_m_s2`)으로 숨겨진 대기밀도·항력 배율을 온라인 추정해 예측 탄착점(IIP) 오차를 공력 양력과 격자핀만으로 발사장 상공까지 유도.
7. **3→1 최소 스로틀 호버슬램 (`landing_burn`, 재점화 #3) & 5초 직립 (`touchdown_settle`)**:
   - 고고도 3엔진 감속(Stage A) → 중앙 1엔진 전환(Stage B, 호버링 불가 Hoverslam).
   - **해석적 자세 복귀 예측기(`_predict_zero_tilt_state`)**로 유한 각가속도(`2.15°/s²`) 복귀 위상지연을 선제 보상해 강풍·돌풍에서도 오버슈트 없이 패드 중앙 정렬.
   - 볼록 최적화(LP) 종말 참조 플래너 및 우선순위 제어 할당(`격자핀 → TVC → RCS`) 적용(저고도 수직 정렬 모드에서 구간 실제 TVC 토크 `sup_mid` 기준 RCS 정합).
   - 접지 직후 엔진 종료 및 **5초 무동력 착륙다리 스프링-댐퍼·마찰 직립 정착** 판정.

## 3. 운용 입력 범위 및 판정 기준

### 허용 입력 범위 (`AprConditions`, `RecoveryDisturbances`, `SensorSettings`)
- 바람/돌풍: 지상풍 `±8 m/s`, 상층풍 `±20 m/s`, 수직풍 `±3 m/s`, 예보 오차 `±2 m/s`, 돌풍 진폭 `0–5 m/s` (주기 `8–60 s`).
- 대기: 지상 기온 `0–35 °C`, 기압 `95–105 kPa`, 대기밀도 배율 `0.90–1.10` (최종 밀도는 기준 대기 대비 ±10% 이내), 위도 `-90° ~ +90°`(코리올리 포함).
- 기체 편차·지연·센서: 추력 배율 `0.97–1.03`, 항력 배율 `0.85–1.15`, 초기 질량 배율 `0.99–1.01`, 관성 배율 `0.97–1.03`, 위치 오차 `0–2 m`, 속도 오차 `0–1 m/s`, 관측 지연 `0–2 step`, 명령 지연 `0–1 step`, 엔진 지연 `0–0.05 s`, 확장 IMU 자세/자이로 잡음·편향(`≤ 0.1°`, `≤ 0.1°/s`, `±0.05`) 및 패킷 누락(`최대 2/20`).

### 합격 판정 기준 (모두 동시 충족)
- **비행 안전**: 최대 동압 `≤ 30 kPa`, 상승 Q-alpha `≤ 150 kPa·deg`, 회복 하중 `≤ 5.0 g`, 최대 각속도 `≤ 15°/s`, 최대 각가속도 `≤ 5.0°/s²`, 짐벌 `≤ 6°`, 핀 힌지 모멘트 `≤ 5,000 N·m`, 질량·헬륨 보존 및 공급·슬로시 정상.
- **최초 접지**: 중심 위치 오차 `|x| ≤ 2.0 m`, 다리 끝점 수직 속도 `≤ 1.5 m/s`, 수평 속도 `≤ 0.5 m/s`, 기울기 `≤ 3.0°`, 각속도 `≤ 0.5°/s`, 주추진제 `> 0 kg`, RCS `≥ 0 kg`, 착륙다리 완전 전개 및 패드 내부 접지.
- **접지 후 5초 직립 (`contact_dynamics`)**: 스트럿 압축 `≤ 0.75 m`, 다리 하중 `≤ 450 kN`, 접촉 하중 `≤ 4.0 g`, 동체 지면 충돌 없음, 5초 무동력 정착 후 직립 유지(`final_tilt ≤ 3.0°`, `final_speed ≤ 0.25 m/s`).
