# 100톤 1단 회수 모델 명세

[English](spec.md) | [README](../README.ko.md)

실물 비행 인증을 받은 기체가 아닌 이론적 **2차원 소프트웨어 모델**입니다.
기준 시드는 **378**입니다. 발사 후 약 37 km에서 콜드 분리하고 1단을 원래
발사장으로 회수합니다. 상단의 500 kg 탑재체와 700 km 원궤도 진입은 성공을
가정하며 2단 비행은 적분하지 않습니다.

선택적인 자세 및 자이로 오차와 패킷 누락, 자세 추정기와 동결 평가의 가정은 [검증 설계](validation.ko.md)에 별도로 명시합니다. 이 문서의 기본 관측 가정은 기존 운용 화면과 회귀 조건에 적용합니다.

## 기체 질량 배분

| 항목 | 질량 |
|---|---:|
| 1단 엔진 | 1,200 kg |
| 1단 구조, 탱크, 시스템 | 8,700 kg |
| 착륙장치 | 1,500 kg |
| 핀과 관련 장치 | 600 kg |
| 1단 건조질량 합계 | 12,000 kg |
| 1단 주 추진제 / RCS 추진제 | 70,200 / 300 kg |
| 1단 초기 질량 | 82,500 kg |
| 2단 건조질량 / 추진제 / 탑재체 | 1,500 / 15,500 / 500 kg |
| 상단 합계 / 총 발사 질량 | 17,500 / 100,000 kg |

1단 몸체는 길이 20 m, 직경 3 m입니다. 상단은 길이 8 m이며 집중 질량중심은
1단 하단에서 24 m에 있습니다.

설치한 핀 4개의 전체 면적은 6 m²이며 평면 등가 면 2개, 전체 유효 면적
3 m²로 계산합니다. 핀 배분 600 kg에는 본체 360 kg, 구동기 160 kg, 전개
장치 60 kg, 전기 장치 20 kg을 포함합니다. 개념상 다리 4개는 반폭 4 m의
평면 발 2개로 표현하며 패드 반폭은 10 m입니다.

공급, 가압, 배플, 분리 장치 1,015 kg은 구조, 시스템 예산 **안에** 포함합니다.
헬륨 65 kg, 용기와 조절 장치 450 kg, 수집 장치 150 kg, 배플 300 kg, 분리 밀기
장치 50 kg입니다. 유지형 액체 버퍼 1,500 kg은 주 추진제의 일부이며 추가
질량이 아닙니다. 실측 부품이나 인증된 설계가 아닌 개념 배분입니다.

| 추진 계통 | 가정 |
|---|---:|
| 해면 추력 / 비추력 | 1.6 MN / 300초 |
| 진공 추력 / 비추력 | 약 1.76 MN / 330초 |
| 스로틀 / 짐벌 범위 | 이상적인 연속 0-100% / ±6° |
| RCS 비추력 / 최대 토크 | 220초 / 100,000 N m |
| RCS 종류 | 화학식 추진기 가정, 질소 냉가스 아님 |
| 주 하강 기준속도 | 1.0 m/s |

노즐 압력 보정에 해당 위치의 기압을 사용합니다. 추력과 추진제 소비는 같은
실제 공급 유량으로 계산하며 RCS가 소진되면 RCS 토크를 사용할 수 없습니다.

## 좌표와 적분하는 물리

발사장이 국소 원점입니다. +x는 동쪽, 오른쪽, +z는 위쪽입니다.
위치는 몸체 하단이나 발이 아닌 순간 전체 질량중심입니다.
자세각은 수직에서 시계방향이며 양의 짐벌은 추력을 시계방향으로 돌립니다.
평면 이동 2개와 회전 1개이며 공간상의 6자유도 모델은 아닙니다.

~~~text
thrust_x = thrust * sin(theta + gimbal)
thrust_z = thrust * cos(theta + gimbal)
clockwise_torque = arm_z * force_x - arm_x * force_z
~~~

추진제 소비, 전개, 분리에 따라 질량, 질량중심, 관성이 바뀝니다. 추력, 공기
상대 운동의 공력, 고도별 중력, 국소 코리올리 투영, RCS와 핀 모멘트, 내부
출렁임을 결합합니다. 출렁임은 전체 질량중심에 대한 몸체 위치를 바꾸며
가상의 외력으로 취급하지 않습니다. 성공을 만들기 위해 접지 때 상태를
덮어쓰지 않습니다.

| 상태 인덱스 | 항목 |
|---|---|
| 0-5 | 질량중심 x/z, vx/vz, 자세각과 각속도 |
| 6-7 | 주 추진제와 RCS 추진제 |
| 8-12 | 다리, 핀 각도, 전개율, 실제 짐벌, 스로틀 |
| 13-14 | 유지형 버퍼 질량과 액체 수집 비율 |
| 15-16 | 탱크 빈 공간과 용기의 헬륨 질량 |
| 17-18 | 출렁임 진자의 호 길이와 속도 |

기체는 19개 상태를 모두 적분합니다. 기본 RK4 간격은 0.010초, 제어 주기는
0.020초입니다. 발 접촉은 사건 검출과 접지 근처의 작은 적분 간격을 사용합니다.
보조 조건 4개는 0.005초 간격으로 검사하며 이것이 연속 운용 범위 전체의
수렴 증명은 아닙니다.

## 공급, 출렁임, 분리

축약 공급 모델은 밀도 826 kg/m³의 등가 액체, 유지형 수집 버퍼 1,500 kg,
최대 공급 650 kg/s를 사용합니다. 액체 수집은 고유 가속도에 의존합니다.
공칭 최대 요구량은 약 543.8 kg/s이며 버퍼는 최대 유량에서 약 2.76초를
지원하고 수집 안정화 시간상수는 0.35초입니다.

~~~text
main_dot = -delivered
buffer_dot = pickup - delivered
bulk_dot = -pickup
~~~

버퍼를 다시 채울 때 추진제를 두 번 소비하지 않으며 무추력 관성 비행에서
정지한 엔진이 액체를 배출하지 않습니다. 공급 부족은 질량유량과 추력을 함께
줄이며 명시적인 실패 검사로 남깁니다.

폐쇄형 등온 헬륨은 두 재고를 보존하며 `p = m*R*T/V`로 계산합니다.
용기는 1.3 m³, 헬륨 총량은 65 kg입니다. 탱크 조절 목표는 연소실 압력이
아닌 350 kPa이며 입구 임계값 220 kPa에 가까워지면 공급이 줄어듭니다.
재점화는 버퍼 350 kg 이상, 탱크 압력 280 kPa 이상을 요구하고 가정한 점화
지연 0.2초를 적용합니다. 용기, 용적, 공급 예산은 이론 정합성 검사입니다.

출렁임은 비선형 평면 진자입니다. 남은 주 액체의 3%가 길이 0.8 m 모드에
참여하며 감쇠비는 0.12입니다. 연성 질량행렬에 몸체, 모드 운동량, 코리올리,
원심 항을 유지합니다. 복원력은 자유낙하에 가상의 중력을 더하지 않고 고유
축방향 가속도를 사용합니다. 모드 구속력 100 kN과 탱크 형상으로 모델 범위를
제한하며 범위를 벗어나면 실패입니다.

분리는 상대 축방향 속도 0.5 m/s, 측면 작용점 차이 2 mm, 등가 펄스 시간
0.15초의 반대 방향 충격량을 적용합니다. 선형, 각운동량과 기존 내부 운동을
이어받습니다. 1단 질량중심으로 좌표를 바꾸지만 속도와 각속도를 0으로
초기화하지 않습니다. 기록한 펄스 평균 각가속도는 순간 충격의 최고값 해석이
아닙니다.

## 유도와 관측

상승은 15초부터 공기 흐름을 따르는 기울임을 시작하며 자세각 상한은 25°입니다.
엔진 종료와 유한한 자세 전환 시간을 예측하고 정지 전에 공기 흐름과 정렬하며
실제 분리 상태를 확인합니다. 회수는 저동압 RCS 전환, 유한 연소 귀환 예측,
사전 진입 제동, 수평 정렬, 수직 종말 착륙으로 구성합니다.
예측기는 축약 유도 모델이지 성공 판정용 전체 시뮬레이션이 아닙니다.

제어기는 지연 텔레메트리, 전달한 명령 이력, 공칭 기체 제원, 예보 기본풍을
사용합니다. 평면 항법 추정기는 위치, 속도, 가속도 편향을 추정합니다.
원시 위치, 속도 오차는 크기가 제한된 2차원 균일 원판 오차이며 원시 오차의
상한이 필터 오차 상한을 보장하지는 않습니다. 숨겨진 실제 바람, 추력, 관성
편차를 제어기에 제공하지 않습니다.

자세, 각속도, 추진제, 구동기에는 이상적인 지연 측정을 가정합니다.
분리 안전과 점화 인터록은 실제 모델 상태, 공급 상태를 사용하며 완전한
실물 센서 구현이 아닙니다. 성공 판정은 별도로 기록한 실제 상태를 사용합니다.

## 허용 환경과 정상 편차

대기는 0-100 km의 층별 정역학 근사입니다. 국소 코리올리 투영의 기본 위도는
37°이며 완전한 3차원 지구 좌표나 실측 발사장 날씨 프로필이 아닙니다.

| 입력 | 허용 범위 |
|---|---|
| 지상 기본 수평풍, 0-50 m | 크기 ≤8 m/s |
| 상층 기본 수평풍 | 크기 ≤20 m/s |
| 유한 수평 돌풍 | 진폭 0-5 m/s |
| 순간 수평풍 | 지상 ≤13 m/s, 상층 ≤25 m/s |
| 기본 수평풍 전단 | ≤4 m/s/km |
| 수직풍 / 전단 | ±3 m/s / ≤3 m/s/km |
| 실제, 예보 기본풍 차이 | ≤2 m/s |
| 최종 밀도 | 고정 기준대기 대비 ±10% |
| 해면 기온 / 기압 | 273.15-308.15 K / 95-105 kPa |
| 위도 | -90°~90° |
| 항력 / 추력 / 1단 관성 배율 | 0.85-1.15 / 0.97-1.03 / 0.97-1.03 |
| 초기 전체 질량 배율 | 0.99-1.01, 약 ±1,000 kg |
| 원시 2차원 위치 / 속도 오차 반경 | ≤2 m / ≤1 m/s |
| 관측 / 명령 지연 | 제어 주기 0-2 / 0-1회 |
| 엔진 지연 | 0-0.05초 |

바람 프로필은 전체 고도 범위를 포함해야 합니다. 선택 기온, 기압 프로필도
전체 범위를 포함해야 합니다. 최종 밀도는 **고정** 기준대기와 비교하므로
기온, 기압, 밀도의 모순된 조합을 거부합니다. 초기 질량 편차는 추가 연료가
아닌 등가 건조 구조에 반영합니다.

돌풍은 유한한 시간, 고도 구간을 사용하며 진폭을 설정한 것만으로 실제 비행의
조우를 보장하지 않습니다. 예보 유도에는 기본 수평풍만 사용합니다.
남아 있는 예보 돌풍 진폭 입력은 검증, 기록하지만 예보 파형을 만들지 않습니다.
실제 수직풍도 예보에는 제공하지 않습니다.

알려진 고장, 날씨와 건전성 검토 미통과, 강수, 뇌우와 우박을 제외합니다.
검토 항목은 번개 해석이나 실제 발사 허가가 아닙니다. 허용 입력도 실제
비행 판정에서는 실패할 수 있습니다.

## 분리와 성공 판정

| 콜드 분리 조건 | 요구 상태 |
|---|---:|
| 질량중심 고도 | 37 ±1 km |
| 주 추진제 | ≥20,000 kg |
| 실제 엔진 스로틀 | ≤0.001 |
| 동압 | ≤25 kPa |
| 각속도 / 받음각 | ≤5°/s / ≤5° |
| 상승 이력 | 최대 동압 구간 통과 후 |

임무 완료, 접지 전 비행 안전, 착륙을 구분하며 적용되는 모든 기준을 통과해야
전체 성공입니다.

| 접지 전 비행 요구사항 | 한계 |
|---|---:|
| 최대 동압 | 30 kPa |
| 상승 Q-alpha | 150 kPa deg |
| 동압 10 kPa 이상 상승 받음각 | 5° |
| 상승 축방향 / 회수 하중 | 3 / 5 g |
| 선언한 절대 가속도 상한 | 6 g |
| 각속도 / 각가속도 | 15°/s / 5°/s² |
| 등가 핀 힌지 모멘트 | 각각 5,000 N m |
| 핀 모델 범위 | 마하 ≤8, 받음각 ≤25° |
| 짐벌 | ±6° |

100톤 질량만으로 인증한 한계가 아닌 개념설계 요구사항입니다. 단순 강도,
힌지 추정은 외피 좌굴, 피로, 진동, 열 손상, 실측 보정한 초음속 핀 지도를
해석하지 않습니다.

| 첫 접지 요구사항 | 한계 |
|---|---:|
| 질량중심 위치 오차 | ≤2 m |
| 발 수직 / 수평속도 | ≤1.5 / ≤0.5 m/s |
| 자세 / 각속도 | ≤3° / ≤0.5°/s |
| 주 추진제 / RCS 잔량 | >0 kg / ≥0 kg |
| 접촉 형상 | 다리 전개, 발이 패드 안, 몸체 충돌 없음 |

`kinematic_touchdown` 평가는 첫 발 접촉에서 종료합니다. 발 속도에는 몸체
회전을 반영하며 위치는 질량중심 기준입니다. 고정된 추가 잔량은 요구하지
않지만 임무를 마치기 전 연료 소진은 실패입니다. 발 수직속도 ≤1.5 m/s에서
다리가 견딘다고 가정합니다. 접촉 힘, 다리 압축, 재료 강도, 엔진 정지 후 거동,
안정 기립은 통과 항목이 아닌 **미평가**입니다.

분리 이후 실행은 주어진 분리 상태를 유지하지만 제어기 기억 상태를 초기화하고
앞선 상승을 미평가로 표시합니다. 전체 비행 성공을 입증하지 않습니다.
재생은 화면 연출이며 접지 때 불꽃을 숨겨도 실제 엔진 종료나 접지 후 운동을
계산하지는 않습니다.

2단 분리 상태가 있는 전체 비행의 재생은 기록된 2단 질량중심 위치, 속도,
각속도를 별도의 상승 연출로 이어갑니다. 연출 엔진은 분리 3초 후 점화하고
1.2초 시간상수로 가정한 추력 가속도 18 m/s²까지 증가하며 각속도에는
4초 감쇠를 적용합니다. 분리 고도의 일정 중력을 포함하는 해석적 표시 곡선이지
가변 질량 2단 운동이나 궤도 해가 아닙니다. 점선 경로는 고도 100 km 또는
기록 종료까지 표시합니다. 이 연출은 시뮬레이션 연료를 소비하거나 1단 상태,
성공 판정, 계산값을 바꾸지 않습니다. 2단 분리 기록이 없거나 회수 전용인
기록에서는 2단 상승을 만들어내지 않습니다. 짧은 영상은 기록 시각의 구간만
선택하며 기본 동작은 전체 비행 렌더입니다.

## 로컬 UI 규약

`ui` 추가 설치는 패키지에 포함한 HTML 화면을 로컬 주소의 FastAPI 앱으로
제공합니다. 비행 계산은 별도의 로컬 프로세스에서 수행합니다. 계산 또는
영상 생성은 한 번에 하나만 실행하며, 화면은 상태만 조회하고 비행을 중복
실행하지 않습니다. 외부 API, 분석 수집, CDN을 사용하지 않습니다. 변경 요청은
앱 세션의 토큰과 동일 출처 검사를 요구하며, 다운로드는 앱이 생성한 결과,
미디어 파일 이름만 허용합니다.

100톤 제원, 시드 378, 활성 핀, 최초 접지 평가, 0.01초 적분 간격을 고정합니다.
환경, 불확실성 입력은 기존 `AprConditions`, `RecoveryDisturbances`로 검증하며
밀도 조합과 고도별 프로필의 제약도 그대로 적용합니다. 계산을 완료한 비행
실패는 결과를 보존하며 프로그램 실행 오류와 구분합니다. 접지가 없어서
측정할 수 없는 값은 0이나 착륙 기준 통과로 표시하지 않습니다.

결과는 계산 기록과 해당 비행의 입력값을 사용합니다. 화면 그래프는 제한된
표본으로 그릴 수 있지만 다운로드 JSON은 전체 기록을 보존합니다. 착륙
속도는 착륙장치 접촉 지점의 운동학 값입니다. 전체 임무에 성공한 결과에서만
기존 기록으로 영상을 생성하며, 영상 구간, 해상도 선택은 성공 판정을 바꾸지
않습니다. MP4는 CPU에서 프레임을 하나씩 그리므로 비행 계산보다 훨씬 오래
걸릴 수 있습니다. 구간이 길고 해상도가 높을수록 작업량이 증가하므로 빠른
미리보기는 640 × 360의 짧은 구간을 권장합니다. 화면은 생성 전과 생성 중에
이를 안내합니다. 앱을 열어 두어야 하며 기록한 그래프와 결과표는 계속 볼 수
있습니다. 고정 대기 시간이나 GPU 렌더링 가속을 보장하지 않습니다.
Windows의 `launch-dm100.bat`는 정상 동작하는 Python 3.12를 찾아 격리된 `.venv`를
만들고 `ui`, `video` 추가 의존성과 프로젝트를 설치합니다. 정상 환경은 재사용하고,
실행할 수 없거나 이전 위치를 가리키는 환경은 보관한 뒤 새로 만듭니다. `python.exe`의
존재만으로 환경이 정상이라고 판단하지 않습니다. 첫 설치와 복구에는 인터넷이
필요합니다. `--setup-only`는 앱을 열지 않고 환경만 준비하며 나머지 인자는 로컬
앱으로 전달합니다. Python 자체는 사용자가 준비해야 하며 자동으로 내려받지 않습니다.
현재는 소스를 설치해 실행하는 프로그램입니다. 새 Windows 설치와 Linux
컨테이너의 검사는 [환경 재현 기록](results/reproduction.json)에 있습니다.
Linux의 한국어 영상 표기에는 한글 글꼴이 필요합니다. 단독 실행파일은 제공하지 않습니다.

## 검증 근거와 한계

최초 기록은 개발 205개, 이미 관측한 회귀 72개, 보조 9개의 전체 비행 검사를
통과했습니다. 본 검사 277개와 보조 9개는 별도 분모입니다. 최소 주 추진제,
RCS 잔량은 2,958.185391 / 95.875194 kg, 최대 RCS 사용은 204.124806 kg입니다.
적분 간격 절반 검사까지 포함한 전체 286개의 발 수직속도 최대값은
1.2550572 m/s입니다.

현재 버전의 회귀 재실행과 새 동결 평가 수치는 [수치 보고서](results.ko.md)에
있습니다. 이전 기록과 새로운 평가 집단의 분모는 구분합니다.

저장소의 `configs/apr-regression-v1.json`은 286개 선언 입력, 시드 방식, 적분
간격을 보존해 같은 조건을 재실행합니다. 알려진 회귀 조건이지 **새 독립
평가가 아닙니다**. 결과에는 실패, 연료 수지, 실제 돌풍 노출, 소스와 입력 해시,
실행 정합성을 남깁니다. 유한한 표본의 성공이 연속 운용 범위를 입증하지는
않습니다.

계산 범위 밖은 추진제 두 종류의 극저온 유동, 비등과 펌프 공동현상, 다중 모드
유체 충돌, 탄성 구조, 연결부와 화약 충격 과도 현상, 연소와 재점화 신뢰도,
2단 점화와 플룸, 2단 궤도 비행, 세부 열과 지면 손상, 다리와 패드 재료 강도입니다.
헬륨 재고 이동은 질량을 보존하지만 재배치에 따른 질량중심 변화는 별도로
적용하지 않습니다. 실측 보정이나 실물 기체 안전 인증을 주장하지 않습니다.
