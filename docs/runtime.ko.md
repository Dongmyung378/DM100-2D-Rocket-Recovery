# 실행 환경 호환성

[English](runtime.md) | [프로젝트](../README.ko.md)

이번 보완은 수치 평가에 사용한 소스와 결과를 유지하면서 설치를 자동화하고,
폰트와 영상 인코더를 프로젝트가 제공하도록 변경했습니다. 수치 계산 버전은
1.1.0이며 실행 환경 보완판의 태그는 `v1.1.0-runtime.1`입니다.

## 자동 설치 지원 환경

- Windows 10/11 x86-64: `launch-dm100.bat` 실행
- glibc 2.28 이상인 Linux x86-64: `sh launch-dm100.sh` 실행
- `--setup-only`로 환경만 준비하고 `--doctor`로 폰트와 인코더 확인

GPU나 시스템 FFmpeg, 한글 폰트, 관리자 권한 설치가 필요하지 않습니다.
기존 Python 3.12를 사용할 수 있으면 재사용합니다. 없으면 uv 0.13.0의 공식
배포 파일과 실행 파일의 SHA256을 확인한 뒤 `.local/uv-python/`에 Python
3.12.15를 준비합니다. 셸 설정이나 Windows 레지스트리는 변경하지 않습니다.
첫 설치와 환경 복구에는 인터넷 연결과 쓰기 가능한 프로젝트 폴더가 필요하며,
Linux의 첫 다운로드에는 curl 또는 wget과 tar/sha256sum을 사용합니다.

실행기는 가상환경의 격리, 현재 소스 경로와 앱 버전, 실제 사용되는 모든 런타임
의존성의 버전을 `requirements/runtime-constraints.txt`와 대조합니다. 동봉한
폰트의 해시와 실제 H.264 인코딩도 확인합니다. 사용할 수 없는 환경은
`.local/environment-backups/`에 보관하고 현재 경로에 다시 구성합니다.

하위 프로세스에서 Python 경로와 pip 설치 위치를 바꾸는 환경변수를 제거하며,
네트워크 인증서와 프록시 설정은 사용할 수 있습니다. 명시한 `DM100_PYTHON`은
Python 3.12여야 합니다. `DM100_USE_MANAGED_PYTHON=1`을 지정하면 기존 Python이
있어도 자동 다운로드 경로를 확인할 수 있습니다.

## 한글과 영상

수정하지 않은 Noto Sans KR과 SIL OFL 1.1 라이선스를 소스 ZIP과 wheel에
포함했습니다. 시스템 폰트 목록을 검색하지 않고 동봉한 글꼴을 등록하므로
최소 Linux 환경에서도 한글 영상을 생성할 수 있습니다. 영상에는 검증한
`imageio-ffmpeg` 패키지의 인코더를 사용합니다.

## 검증 범위

[호환성 검증 기록](results/runtime-compatibility.json)에 Windows와 Linux의
관리형 Python 3.12.15 새 환경, 한글과 공백 경로, 로컬 HTTP 실행과 한글
H.264 영상 생성, 환경변수 오염과 오프라인 재사용, 의존성 버전 불일치의
자동 복구 및 wheel 설치 확인을 기록했습니다. 글꼴 누락 경고도 실패로
처리합니다. 같은 컴퓨터의 별도 환경을 사용한 검증입니다. 공개하지 않은
과거 기록이 필요한 선택적 검사 1개는 건너뜁니다.

수치 평가에 연결된 소스 파일 17개는 기존 해시를 유지합니다.
`reproduction.json`은 당시 수행한 검증 기록으로 보존하고, 이후 실행 환경
보완의 결과는 별도 호환성 기록으로 제공합니다.
