# 모델 카드: 평면 BC 및 DAgger 착륙 정책 (35일차)

[English model card](model-card.md)

상태: 시뮬레이션 연구용입니다. 두 모델 모두 실제 하드웨어나 안전 필수 제어에 사용할 수준이 아닙니다.

## 시스템과 데이터 출처

시뮬레이터의 상태는 `(x, z, vx, vz, theta, omega, mass)` 7개, 행동은 `(throttle, gimbal)` 2개입니다. Python 3.12.7과 설정된 0.02초 RK4 물리를 사용하며 학습 정책은 0.1초마다 새 명령을 냅니다. 입력과 목표 정규화 통계는 24일차 train split만으로 계산했습니다. 채택된 offline 데이터는 train 궤적 1,007개(상태-행동쌍 100,700개), IID validation 100개, hard OOD test 191개입니다. 계획된 hard test 중 9개는 Teacher 재적분 검증에 실패해 191건 비교에서 제외됐습니다.

BC checkpoint는 25일차 `7-64-64-2` ReLU MLP입니다. 26일차의 tanh 및 더 넓은 ReLU 변형은 IID 검증 정규화 MSE `0.03098`을 넘지 못했습니다. DAgger v4는 이 BC에서 시작해 학생이 방문한 **train split** 상태에 대해 최적제어 Teacher가 새로 푼 라벨 125개를 추가했습니다. 세 반복의 Teacher 채택 수는 43/48, 35/48, 47/48입니다. 실패한 질의는 학습 라벨에 넣지 않았습니다. 최종 DAgger 평가에는 throttle `2/s`, gimbal `60 deg/s` 명령 변화율 제한을 적용했고 BC 비교에는 이 후처리를 적용하지 않았습니다. Checkpoint metadata에는 정규화, 구조, 학습 설정, 데이터 출처와 부모 digest를 기록했으며 변화율 제한 선택은 33~34일차 보고서에 별도로 남겼습니다.

## 평가

| 평가 집합·정책 | 안전 착륙 | 해석 |
|---|---:|---|
| IID validation, BC | 14/100 | 단일 행동 오차에 비해 폐루프 성공률이 낮습니다. |
| IID validation, DAgger + 변화율 제한 | 11/100 | 명목 성능을 유지하지 못했습니다. |
| Hard OOD test, BC | 0/191 | 안전 착륙이 없습니다. |
| Hard OOD test, DAgger + 변화율 제한 | 3/191 (1.6%) | 소폭 개선이나 강건한 제어는 아닙니다. |
| Hard OOD test, 동결 PID | 191/191 | 채택된 이 평가 집합의 강한 고전제어 기준선입니다. |

Hard test 초기 조건을 읽기 전에 BC·DAgger checkpoint를 복사하고 SHA-256을 확인했습니다. Hard test는 모델 구조, DAgger 반복, 변화율 제한이나 PID 혼합 비율 선택에 사용하지 않았습니다. DAgger가 BC보다 개선한 case는 71, 98, 125번입니다. 실패·개선 MP4 및 JSON 재생 기록은 Git에서 제외된 `artifacts/day35-final/`에 있습니다.

Hard OOD에서 DAgger 실패는 연료 고갈 110건, 위치 오차 41건, 자세 오차 32건, 접지 속도 초과 5건입니다. BC는 각각 124, 38, 26, 3건입니다. DAgger 연료 고갈 사례의 에피소드 시간 중앙값은 48.96초, 고갈 순간 수직속도 절댓값 중앙값은 0.255 m/s여서 과도한 호버링과 일치합니다. 개발 장비의 추론만 측정한 중앙값은 BC 9.4 μs, DAgger 9.5 μs입니다. 센서·시뮬레이션·구동기 시간은 제외합니다. 과거 Teacher의 채택된 풀이 시도 평균은 1.236초였으므로 두 수치를 전체 시스템 속도 비교로 해석하면 안 됩니다.

## 알려진 한계와 실패 원인

- Hard test 초기 조건 191개 모두가 **x, z, vz, mass**에서 train 초기 조건의 최소·최대 범위 밖입니다. 예를 들어 train 초기 고도는 70.01~107.98 m, hard test는 110.87~139.95 m이며 질량은 각각 962.07~999.98 kg, 900.28~959.56 kg입니다. 이는 의도한 OOD 스트레스이며 IID 성능 추정치가 아닙니다.
- DAgger 라벨 125개는 학생이 방문할 수 있는 상태공간에 비해 적습니다. 32건 개발 집합에서는 BC 4/32에서 DAgger 5/32로 늘었지만 전체 IID validation에서는 14/100에서 11/100으로 떨어졌습니다. 따라서 32일차의 명목 성능 비하락 목표는 **미달**입니다.
- Teacher도 완전하지 않습니다. 학생 상태 질의 144건 중 19건이 실패했고 계획된 hard test 200건 중 9건은 Teacher 재적분에 실패했습니다. 채택된 191건에는 풀기 쉬운 사례 쪽 선택 편향이 있습니다. 다만 이 실패만으로 BC와 PID의 큰 격차를 설명하기는 어렵습니다.
- 모델은 기억·불확실성 추정·안전 장치·비행 단계 로직이 없는 2층 feed-forward 정책입니다. 행동 오차 손실은 착륙 실패나 연료 고갈 호버링을 직접 벌점으로 주지 않습니다.
- 변화율 제한은 검증 32건에서 급격한 명령을 줄였지만 착륙 수 `3/32`는 늘리지 못했습니다. 센서 오차 또는 바람 0.8 m/s와 추력 5% 저하를 넣으면 각각 `2/32`가 됩니다. Train 20,000행에만 센서 오차를 더한 별도 증강 후보는 원래 상태 `5/32`, 센서 오차 `2/32`여서 센서 강건성은 늘지 않았습니다. 이 후보는 이미 동결한 hard test 비교에 넣지 않았습니다. PID/DAgger 혼합 정책 세 개는 모두 `0/32`여서 채택하지 않았고, 선택 사항인 PPO는 학습하지 않았습니다.
- 환경은 평면 착륙 직전 하강과 점 접촉만 모델링합니다. 발사, 3D 회전, 착륙 다리, 충격 손상이나 하드웨어급 구동기는 포함하지 않습니다. 시뮬레이션 성공 기준 2 m/s는 실제 안전 착륙을 증명하지 않습니다.
